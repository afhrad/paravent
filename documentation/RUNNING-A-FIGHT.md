# Running a fight

The gamemaster's walkthrough of a fight ships with the app, in each language it is written
in: [`app/help/combat.en.md`](../app/help/combat.en.md) and
[`app/help/combat.de.md`](../app/help/combat.de.md). It opens from the combat tracker's
**?** button (`/help/combat`), in the reader's language with English as the fallback.

The rules behind it are in [COMBAT.md](COMBAT.md). When the tracker changes, update both
help files with it — a test checks they name the same sections.
