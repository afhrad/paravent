# Paravent – Icon-Set (Variante A)

Farben: Akzent #4560DC · Flügel #A7B7FA · Mittelpaneel #FFFFFF

| Ordner | Inhalt |
|---|---|
| svg/ | paravent-icon.svg (abgerundete Kachel), paravent-icon-square.svg (randlos), paravent-mark.svg / -dark.svg (nur Symbol, transparent) |
| png/ | Kachel 128–1024 px und Symbol 256–1024 px, alles mit transparentem Hintergrund |
| app-icon/ | iOS 1024 (ohne Alpha, iOS rundet selbst), apple-touch-icon 180, Android/PWA 192/512, maskable 512, site.webmanifest |
| favicon/ | favicon.ico (16/32/48), favicon-16/32.png, favicon.svg |

## Einbindung im <head>

```html
<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#4560DC">
```
