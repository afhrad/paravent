Design reference

Twelve standalone pages, each covering one part of the interface. Open any file directly in a browser — no server, no build step. The written specification lives in DESIGN.md; these pages are what it looks like.

Resuming this work?

Read HANDOFF.md first — the decisions and their reasons, what was measured rather than assumed, and the two open questions still needing an answer.

The shared/ files are the source of truth

Each page inlines them at build time so it opens from the filesystem with no server. When a token changes, change it in shared/tokens.css and re-run split.py — never edit a generated page directly.
